# 🎬 유튜브 트랜스크립트 · 구조 증류 리더

유튜브 링크를 던지면 **영상 구조를 타임스탬프 목차로 요약**하고, **자막을 한글·원문 병기로 충실히 정리**해
바로 읽을 수 있는 자료로 만들어 줍니다. 독자 페르소나는 **SK하이닉스 반도체 마케터(AI 동향 관심)** 로
맞춰져 있어, 요약·인사이트가 그 관점에서 정리됩니다.

> **🎯 맥락 주입**: 페르소나(반도체 마케터)는 고정하되, 화면의 **“맥락 추가”** 에 관심사·배경
> (예: “나는 HBM 영업 담당, 경쟁사 로드맵·고객 채택 신호에 관심”)을 적으면 핵심 시사점·마케터 관점이
> 그 초점에 맞춰 더 날카로워집니다. 맥락은 브라우저에 저장돼 다음 영상에도 자동 적용되고, 언제든 수정/비우기 가능합니다.
> (원문에 없는 사실을 지어내지 않도록 가드레일이 걸려 있습니다.)
>
> **🧠 내 글들로 나를 정의**: 버튼 한 번이면 *지금까지 읽은 글들의 요약만* 보고 “나는 누구인가”를
> 한 문단으로 추론해 위 관점에 자동으로 채워줍니다(요약만 보내 저비용). “글 추가 시 자동 갱신”을 켜면
> 새 영상을 정리할 때마다 프로필이 갱신됩니다. 단, **직접 손으로 고친 관점은 자동 갱신이 덮어쓰지 않습니다.**

## 어떻게 동작하나

```
유튜브 링크 → (서버) 자막 수집 → (브라우저가 본인 키로 직접) Claude 증류 → 구조 요약 + 병기 트랜스크립트 + 보관함
```

**아키텍처 — 서버는 자막만, 무거운 호출은 브라우저가 직접:**
- **서버(Render)**: 자막 수집만 담당 (작고 빠름).
- **브라우저**: 무거운 Claude 호출을 사용자 **본인 API 키로 api.anthropic.com 에 직접** 보냄.
  - Render(무료) → Anthropic 연결이 길거나 동시 다발이면 `premature close`로 끊기던 문제를 **근본 우회**.
  - 키는 **브라우저(localStorage)에만** 저장되고 서버로 가지 않음. Anthropic이 공식 허용하는
    브라우저 직접 호출(`anthropic-dangerous-direct-browser-access`)을 사용.

**자막 수집 전략:**
1. 링크만 붙이면 영상의 자막 트랙을 자동 추출 (타임스탬프 보존)
2. 자막이 없거나 차단되면 → 화면에서 **자막 직접 붙여넣기**로 우회

**처리 전략 (단일 패스 + 자동 분할):**
- 짧은 영상은 **한 번의 호출**로 전체 정리
- 긴 영상은 **구조 요약(1회) + 트랜스크립트(작은 청크 병렬)** 로 분할 — 끊김·잘림 방지, 시간 단축

**결과물** (반도체 마케터 · AI 동향 관점):
- 한 줄 핵심 (증류) · 이 영상의 주제·맥락
- 💡 핵심 시사점 · 📌 마케터 인사이트(연관도 정직 표시)
- 🧭 타임스탬프 구조 요약 — 각 챕터를 **그 자체로 파악되는 충실한 요약**으로, 클릭하면 임베드 플레이어가 해당 시점으로 점프하고 트랜스크립트로도 이동
- 📝 한글·원문 병기 트랜스크립트 (요약 아님, 정보 손실 최소화) — **번역투를 지양한 자연스러운 우리말**(『이렇게 해야 바로 쓴다』 원칙 반영)
- 핵심 용어·숫자 풀이
- → 보관함에 저장되고 검색 가능

**읽기 편의:**
- **섹션 접기/펼치기** — 결과가 길어서 섹션별로 접을 수 있고(트랜스크립트는 기본 접힘), 상단 **미니 목차**로 바로 이동
- **구조 요약 ↔ 트랜스크립트 양방향 링크** — 챕터 → 해당 본문, 본문 문단 → 속한 챕터로 서로 점프
- **트랜스크립트 내 검색** — 현재 영상 본문에서 키워드 찾기
- **📸 자막 캡쳐** — 트랜스크립트에서 원문(또는 📸)을 누르면 **그 시점 영상 프레임 + 한/영 자막**을 사진처럼 만들어 다운로드·복사.
  유튜브 미리보기 프레임(storyboard)을 서버가 프록시해 캔버스로 합성한다. 프레임을 못 가져오면(짧은 영상·라이브, 또는 클라우드 IP 차단) 대표 썸네일 위 자막 카드로 폴백.
  · 정밀한 그 순간 프레임을 원하면 서버에 `YT_PROXY`(주거용 프록시)를 설정하면 차단을 우회한다.

엔진(브라우저가 직접 호출, thinking 끔) — **하이브리드**:
- 트랜스크립트(번역·정리, 토큰 대부분): **`claude-haiku-4-5`** (가장 저렴)
- 구조 요약(시사점·마케터 관점·챕터, 작은 호출 1회): **`claude-sonnet-5`** (인사이트 품질↑, 영상당 1회라 비용 영향 작음)

## 준비물

1. **Node.js 20 이상** — https://nodejs.org
2. **Anthropic API 키** — https://console.anthropic.com (서버가 아니라 **웹 화면 ☰ 에서** 입력, 브라우저에만 저장)
3. (추천) **Supadata 키** — 링크 자동 자막 추출 안정화 (`SUPADATA_API_KEY`, 서버 환경변수)

## 실행 방법

```bash
npm install
cp .env.example .env      # (선택) SUPADATA_API_KEY 등 자막 키만 입력
npm start                 # http://localhost:3000  → 화면 ☰ 에서 Anthropic 키 입력
```

## 클라우드 배포 (폰·PC 어디서나 쓰기)

노트북을 켜둘 필요 없이 항상 떠 있는 주소를 만들려면 → [`DEPLOY.md`](DEPLOY.md) (Render 무료 배포, 클릭 위주 안내).
[`render.yaml`](render.yaml) 블루프린트가 포함되어 있어 저장소만 연결하면 서비스가 자동 생성됩니다.
서버에는 **자막 키(`SUPADATA_API_KEY`)만** 넣으면 되고, **Anthropic 키는 각 사용자가 웹 화면 ☰ 에서**
본인 키를 입력합니다(브라우저에만 저장).

> **🎫 공개 URL이면 접근 토큰 권장**: 서버 자막 수집(`/api/transcript`)은 네 `SUPADATA_API_KEY`
> 쿼터를 쓴다. URL을 공유·공개하면 남이 이 엔드포인트로 네 쿼터를 소진할 수 있으니,
> 서버 환경변수 `APP_ACCESS_TOKEN`(아무 긴 무작위 문자열)을 설정하면 그 토큰을 아는 사람만
> 자막 수집을 쓸 수 있다. 사용자는 웹 화면 ☰ 에 같은 토큰을 넣는다(브라우저에만 저장).
> 비워두면 기존처럼 공개로 동작한다.

## 데이터 · 백업

- 보관함·트랜스크립트·2차 명령 결과는 **이 브라우저(IndexedDB)에만** 저장됩니다(서버 백업 없음, 기기 간 동기화 없음). IndexedDB는 localStorage의 ~5MB 한도가 없어 긴 영상을 많이 모아도 여유롭고, 항목별로 저장해 쓰기 부담도 작습니다. (기존 localStorage 보관함이 있으면 첫 실행 때 자동으로 IndexedDB로 옮깁니다. IndexedDB를 못 쓰는 환경에서는 자동으로 localStorage로 폴백합니다.)
- ☰ 서랍의 **⬇ 보관함 백업(내보내기)** 로 JSON 파일을 내려받아 보관하고, **⬆ 가져오기** 로 복원·이전할 수 있습니다(중복은 갱신, 나머지는 병합). 브라우저 데이터를 지우면 보관함도 사라지니 **중요한 자료는 내보내기로 백업**하세요.
- 저장에 실패하면(공간 부족 등) 조용히 깨지지 않고 경고가 뜹니다 → 백업 후 오래된 영상을 삭제해 정리하세요.

## 사용법

1. 상단에 유튜브 링크를 붙여넣고 **증류**(또는 Enter)
2. 잠시 후(긴 영상은 1~2분) 구조 요약과 병기 트랜스크립트가 표시되고 왼쪽 보관함에 저장됨
3. 챕터의 타임스탬프를 클릭하면 임베드 플레이어가 그 지점으로 이동
4. 자막이 막힌 영상은 → "자막 직접 붙여넣기"로 트랜스크립트를 붙여넣어 처리

## 파일 구성

```
src/server.js               서버 (링크 → 자막 수집 + 스토리보드/이미지 프록시)
src/lib/fetchTranscript.js  자막 수집 (Supadata 등)
src/lib/storyboard.js       유튜브 미리보기 프레임(storyboard) 스펙 파싱 — 자막 캡쳐용
public/distill.js           브라우저 증류 (본인 키로 Claude 직접 호출, 구조 요약 + 병기 트랜스크립트)
public/app.js               화면 로직 + API 키 관리(localStorage) + 보관함
public/                     화면(UI) + 임베드 플레이어
```

> 참고: 옛 서버측 `src/lib/distill.js`는 브라우저 직접 호출(`public/distill.js`)로 대체되었습니다.

## 참고 / 한계

- 일부 영상(자막 없음·연령 제한·지역 차단)은 자동 추출이 막힐 수 있어요 → 자막 붙여넣기로 우회
- 클라우드(데이터센터) IP는 유튜브가 자동 추출을 더 자주 차단할 수 있습니다 → 그때도 붙여넣기로 처리
- 보관함 데이터는 사용하는 브라우저(localStorage)에만 저장됩니다
